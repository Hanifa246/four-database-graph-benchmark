NEO4J VS COGNODB GRAPH DATABASE BENCHMARK

1. Dataset

The benchmark was performed using a graph dataset containing:
- 100,000 relationships
- 169,870 unique nodes
- 90,922 unique source nodes
- 91,094 unique target nodes

2. Benchmark Methodology

Six graph queries were evaluated:
1. Node Count
2. Relationship Count
3. One-Hop Traversal
4. Two-Hop Traversal
5. Three-Hop Traversal
6. Degree Query

Each query was executed 20 times, and average, minimum, maximum, and median execution times were recorded.

5. Overall Results

Average CognoDB slowdown: 24.27x
Overall Neo4j improvement: 87.27%

6. Conclusion

Under the tested experimental conditions, Neo4j demonstrated lower query execution times than CognoDB across all evaluated workloads.

Neo4j achieved an average execution time of 86.68 ms, while CognoDB required 680.82 ms on average. This represents an 87.27% reduction in average execution time.

Neo4j showed the largest performance advantages for node and relationship counting queries, while the advantage was smaller for the degree query. Overall, the benchmark demonstrates that Neo4j provided better query execution performance for the tested graph workloads.
